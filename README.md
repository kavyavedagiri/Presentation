# Kavya — engineering journey

Interactive, offline presentation for a ~20-minute interview introduction.

## Open it

1. Open `index.html` in Chrome, Edge, or Firefox (from this folder so the screenshots resolve).
2. Press **F** for fullscreen, **→** or **Space** to advance, **N** for speaker notes, **T** for a 20-minute countdown, **Home** to return to the start.

No account, CDN, or build step is required.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The presentation |
| `assets/presentation.css` | Visual design |
| `assets/presentation.js` | Keyboard, progress, notes, timer |
| `SPEAKER-SCRIPT.md` | Full spoken script (British English) |
| `PREPARE.md` | Confirm-before-interview list and likely questions |
| `ndots/`, `mutual funds/` | Real screenshots used in the deck |

## Reuse as slides

The twelve sections in `index.html` and the matching script in `SPEAKER-SCRIPT.md` are the same outline. If you need PowerPoint, copy each section’s title, five bullets, and diagram — do not paste the speaker notes onto the slides.

## Honesty rule

Anything marked `[CONFIRM]` or “Placeholder” is unknown or unverified. Do not improvise metrics around it.
